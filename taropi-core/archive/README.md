# /archive 原地归档会话

输入 `/archive`，确认后中止当前运行，再把旧内容另存为同目录的可恢复会话。当前会话在**原路径、原文件名**重建并重载：保留原 id、cwd、parentSession 和会话名，上下文完全清空，不生成交接摘要或提示消息。归档不请求模型。

```text
2026-10-21T14-41-37-047Z_原id.jsonl          ← 原 id，空会话，继续使用
持续工作-archived-2026-10-23-20-45.jsonl    ← 命名会话，新 id，完整旧内容
首条用户消息-archived-2026-10-23-20-45.jsonl ← 未命名会话，新 id，完整旧内容
```

## 名称、检索与恢复

归档名称按规则生成。命名会话使用当前会话名；未命名或空白名称使用当前分支第一条用户可见文本。名称清理 Markdown 和文件名非法字符，最多 30 个 Unicode 字符。两者都没有可用文本时使用 `session`。不发送会话内容，不产生模型延迟、token 或费用。

`/resume` 显示名称与文件名一致，均为 `<归档名称>-archived-YYYY-MM-DD-HH-mm`，时间为本机时区的分钟。同一分钟已有同名文件时追加 `-2`、`-3`，显示名同步带上该序号，不覆盖已有归档。当前会话原名不变，已有归档不自动迁移。

TUI/RPC 可以取消确认。取消时运行中的任务已经停止，但原文件不改动。没有 UI 的宿主直接执行，未持久化或尚未落盘的会话只提示不处理。

归档文件的 header.id 改为新 UUID，并追加上述组合名称，其余原始条目保持不变，包括所有树分支、压缩、工具结果及 context_edit。归档可以在 `/resume` 搜索、选中并恢复，也可以直接启动：

```bash
pi --session '<会话目录>/持续工作-archived-2026-10-23-20-45.jsonl'
```

原 id 的查找仍指向当前会话，不会被归档抢占。归档并非逐字节原样备份，因为 header id 和显示名称需要改变。

## 界面与状态

重载使用 Pi 原生 `switchSession`：聊天区清空，回到保留启动头部的空会话界面，不重新弹启动通知。`quietStartup` 隐藏头部时仍遵循用户设置。不写入任何额外提示消息；归档路径只通知一次。模型、思考级别按宿主的新会话默认配置初始化，与 `/new` 一致。

运行中的回复、工具、压缩、重试通过 Pi 的 abort 停止；交互模式中的排队文本沿用 Pi 的行为回到编辑器，不自动执行。其他扩展仍收到原生 session_shutdown/session_start。

plan 自行比较活动计划创建时间与新 header 时间：会话在计划之后重建时，标记 plan 为 `exited`，清除待启动标志并保持 idle。计划正文保留。归档换用新 id，不继承原会话的活动 plan。不会特别感知其他应用或扩展状态。

## 安全与失败恢复

- 归档文件通过 `wx` 排他写入，文件权限为 `0600`；当前会话用同目录临时文件 + rename 替换。替换失败保留原文件，并清理本次归档及临时文件。
- switchSession 取消或在旧 runtime 仍有效时失败：先原子恢复原始内容，成功后再清理本次归档。回滚失败保留归档，错误给出备份路径。
- 若 runtime 已失效才报错：尽力恢复原文件，同时保留归档，不使用过期 ctx。需要重新启动；不能将磁盘恢复等同于内存恢复。
- Pi 先打开新文件，再关闭旧 runtime。关闭期间旧扩展的追加写入会落在原路径；切换完成后按新 SessionManager 的 header + entries 重写并告警，不将这些收尾条目迁入归档。校验失败时保留归档并明确告警。
- 两个文件的替换不是一个跨文件事务，进程崩溃可能留下归档副本或临时文件；没有自动崩溃恢复。通过归档路径重新打开，或停止所有使用该路径的进程后手动恢复。
- 不协调 CheesePi 或其他 Pi 进程。并发使用原路径可能交错写入，归档前应由用户自行停止其他写入者。
- 计划失效判断依赖时间，系统时钟回拨可能漏判；其他方式重建同 id 会话也会终止旧 plan。
- 归档不会自动清理，会持续占用磁盘空间。

## 校验与体验

相邻测试覆盖命名／未命名会话的规则名称、30 字截断、同分钟序号、文件恢复、排他冲突、写入失败降级、取消、runtime 失效、关闭阶段写入，以及真实 AgentSessionRuntime 的原路径续接、下一次请求不含旧消息、归档检索恢复和 plan 退出。provider 为 mock，不访问真实用户会话或网络；未据此宣称真实 provider 缓存或终端绘制通过。
